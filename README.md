# Urban Soles

Responsive Express/EJS storefront with a React, React Three Fiber, and GSAP product hero.

## Run locally

```sh
npm install
npm run build
npm run dev
```

The cart is stored in the browser under `urban-soles-cart`. The checkout page validates
delivery details and shows the order summary, but order creation, inventory management,
and payment processing require a backend and a payment-gateway integration.
